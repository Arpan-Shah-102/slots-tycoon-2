# Slots Tycoon 2

Slots Tycoon 2 is a major revamp of the original game, keeping all of the core features of Slots Tycoon except loans, while adding new systems, more depth, and a refreshed experience overall.

Spin the reels, manage your money, unlock achievements, and work toward bigger rewards across expanded game modes, currencies, and upgrades. Slots Tycoon 2 builds on the original with major improvements to gameplay, balance, visuals, and progression.

## Current Features (More Soon!)
- Multiple game modes: Slot Machine, Crypto, and The World
- Three currencies: Money ($), Crypto (₡), and Stardust (✺)
- Slot Machine features:
	- Spinning reels
	- Pity jackpot mechanic
	- Payout tiers with upgradeable payouts and stat tracking
	- Purchasable auto spin
	- Upgrades (rig, payout, cashback, pity) with level caps and prices
	- Drip that can give bonuses
	- Themes with bonus and vanity effects
	- Lootboxes with randomized prizes (money, themes, hacking terminal)
	- Trophies
- Crypto Features:
	- Clicking coin to earn crypto
	- Crypto wallet and balance tracking
	- Buyable crypto upgrades and boosts
	- NFTs and collectible crypto assets
	- Lootboxes with randomized rewards
	- Currency exchange between money and crypto
	- Crypto-themed achievements and stats
- The World Features:
	- TBD
- Achievement system
- Admin panel
- Hacking terminal
- Currency exchange
- Sound effects
- Persistent game data with LocalStorage
- Stats and progression tracking
#### Note: Only Slot Machine and Crypto fully work right now!!
